Objetivo del ejercicio

Definir las tablas de la base de datos VENTAS y sus relaciones de acuerdo con el SQL original del ejercicio.

Tablas del ejercicio ⌄

La estructura, las claves y los campos que se describen a continuación corresponden al archivo original ventas.sql.

categorias

Catálogo de categorías. PK: id_categoria. Incluye nombre (obligatorio) y descripcion.

proveedores

Datos fiscales y de contacto del proveedor: cif_nif (PK), nombre, dirección, teléfono y página web. nombre es obligatorio.

clientes

Datos fiscales y dirección del cliente. PK: cif_nif; nombre es obligatorio. Los teléfonos se almacenan aparte.

telefonos

Teléfonos de contacto de clientes. PK autoincremental: id_telefono; FK cif_nif referencia clientes(cif_nif). El número y el cliente son obligatorios.

productos

Productos con PK autoincremental id_producto. Nombre, precio actual, stock, proveedor y categoría son obligatorios; cif_nif e id_categoria son FK a sus respectivas tablas.

facturas

Facturas con PK autoincremental id_factura, fecha y cliente obligatorios. El cliente se referencia con FK cif_nif; descuento admite NULL y se guarda el importe total.

facturas_lineas

Detalle de productos por factura: precio de venta, cantidad, factura y producto son obligatorios. PK compuesta por (id_factura, num_linea); id_factura referencia facturas e id_producto referencia productos.

Claves y relaciones ⌄
Clave primaria (PK)
Identifica de forma única cada fila de una tabla.
Clave foránea (FK)
Referencia una clave de otra tabla para relacionar registros.
Clave primaria compuesta
En facturas_lineas, la combinación (id_factura, num_linea) identifica cada línea de una factura.

Relaciones definidas por las FK

  • Un cliente puede tener varios teléfonos: telefonos.cif_nif → clientes.cif_nif.
  • Los productos referencian un proveedor y una categoría: productos.cif_nif → proveedores.cif_nif y productos.id_categoria → categorias.id_categoria.
  • Cada factura referencia un cliente: facturas.cif_nif → clientes.cif_nif.
  • Cada línea referencia una factura y un producto: facturas_lineas.id_factura → facturas.id_factura y facturas_lineas.id_producto → productos.id_producto. Así, las líneas representan los productos incluidos en las facturas.
