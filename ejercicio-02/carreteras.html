Objetivo del ejercicio

Definir las tablas de la base de datos CARRETERAS y sus relaciones de acuerdo con el SQL original del ejercicio.

Tablas del ejercicio ⌄

La estructura, las claves y los campos que se describen a continuación corresponden al archivo original carreteras-1.sql.

categorias

Clasificación de carreteras. PK: id_categoria. Nombre y descripción obligatorios.

carreteras

PK: codigo. Incluye nombre, prefijo, color, señal, observaciones, titularidad, nivel, tipo de vía, acceso controlado y doble calzada. FK obligatoria id_categoria. El nivel admite 1, 2, 3 o NULL.

comunidades_autonomas

PK autoincremental: id_comunidad. Nombre obligatorio.

provincias

PK autoincremental: id_provincia. Nombre y FK id_comunidad obligatorios.

tramos

PK autoincremental: id_tramo. Referencia una carretera y las provincias de inicio y fin. Registra kilómetros inicial y final, terreno, entorno, velocidad límite y carriles por sentido. El SQL no define una columna de longitud calculada.

extremos_carretera

PK autoincremental: id_extremo. Registra posición (Inicio o Final), tipo (Fisico o Confluencia), kilómetro, carretera, tramo y provincia. Datos de confluencia opcionales. UNIQUE (codigo_carretera, posicion) permite como máximo un extremo de cada posición por carretera.

trayectos

Pasos de un tramo por provincias e intervalos kilométricos. PK compuesta: (id_tramo, id_paso). FK a tramos y provincias.

Claves y relaciones ⌄
Clave primaria (PK)
Identifica de forma única cada fila de una tabla.
Clave foránea (FK)
Referencia una clave de otra tabla para relacionar registros.
Clave primaria compuesta
En trayectos, la combinación (id_tramo, id_paso) identifica cada paso de un tramo por una provincia.

Relaciones definidas por las FK

  • Cada carretera referencia una categoría mediante carreteras.id_categoria.
  • Cada provincia pertenece a una comunidad autónoma mediante provincias.id_comunidad.
  • Cada tramo referencia una carretera y sus provincias de inicio y fin mediante codigo_carretera, id_provincia_inicio e id_provincia_fin.
  • Cada extremo referencia una carretera, una provincia y un tramo de esa misma carretera mediante la FK compuesta (codigo_carretera, id_tramo). Las FK opcionales de confluencia referencian un tramo y una provincia.
  • Los trayectos relacionan tramos y provincias mediante id_tramo e id_provincia, registrando los kilómetros recorridos por cada provincia.
