¿Qué es DDL?

El Lenguaje de Definición de Datos permite crear y modificar objetos de una base de datos. En esta unidad se trabajan CREATE para crear estructuras, ALTER para modificarlas, DROP para eliminarlas y TRUNCATE para vaciar una tabla.
